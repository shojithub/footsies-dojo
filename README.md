# 🥋 1D FOOTSIES P2P - スマホ格ゲー反復道場

対空リアクション・差し返し・密着3すくみ（じゃんけん）をスマホで反復練習でき、さらに **WebRTC DataChannel (P2P) ＋ ロールバックネットコード** によって Android（モバイル回線）と iPad（Wi-Fi）など2台の端末で直接通信対戦ができるトレーニングアプリです。

## 📱 スマホ・タブレットへの「アプリ化（ホーム画面追加）」手順

1. GitHub Pages で公開されたURLをスマホ/タブレットで開きます。
2. **iPad / iPhone (Safari) の場合：**
   * 画面上部（または下部）の「共有ボタン（四角から上矢印）」をタップ ➔ **「ホーム画面に追加」** をタップ。
3. **Android (Chrome) の場合：**
   * 右上のメニュー「⋮」をタップ ➔ **「アプリをインストール」**（または「ホーム画面に追加」）をタップ。
4. ホーム画面に専用アイコン『**格ゲー道場P2P**』が追加され、タップするとアドレスバーなしのフルスクリーンアプリとして起動します！

## 📡 Android（モバイル） ⇔ iPad（Wi-Fi）での P2P通信対戦のやり方

1. 両方の端末でアプリを起動し、右上の **「📡 P2P対戦」** ボタンをタップします。
2. **1P側（例：iPad）** で **「部屋を作って4桁番号を発行」** をタップすると、`4829` のような4桁の数字が表示されます。
3. **2P側（例：Android）** でその4桁の数字を入力し、**「接続！」** をタップします。
4. STUN/TURN サーバー経由で NAT越えを行い、約1〜2秒で直接P2P接続が完了し、リアルタイム対戦が始まります！
   * 2P側（ゲスト側）の端末では自動的に右側のキャラクターが自キャラになり、「🙈 目隠し」ボタンも自動的に自分側（右側）を隠して相手キャラ（左側）だけが見えるように動作します。
